Lumos

Política de Privacidade

Última atualização: 26 de outubro de 2026

Esta Política explica como a Lumos ([RAZÃO SOCIAL], CNPJ [CNPJ]) trata dados pessoais, de acordo com a Lei Geral de Proteção de Dados (Lei 13.709/2018, LGPD).

1. Quais dados tratamos

  • Dos nossos clientes (estabelecimentos): nome, e-mail, telefone, CPF ou CNPJ, dados do negócio, dados de acesso e de uso do sistema, e informações de pagamento da assinatura (os dados do cartão ficam com a instituição de pagamento).
  • Dos clientes dos estabelecimentos: nome, telefone, mensagens trocadas no WhatsApp, pedidos, reservas, histórico de consumo, CPF quando informado na nota fiscal, aniversário e autorização para receber promoções, quando informados.
  • Dos funcionários dos estabelecimentos: nome, usuário de acesso e registro das ações no sistema.

2. Quem decide sobre os dados

Para os dados dos nossos clientes, a Lumos é a controladora. Para os dados dos clientes e funcionários dos estabelecimentos, o estabelecimento é o controlador, e a Lumos é a operadora: trata esses dados somente para prestar o serviço e conforme as instruções do estabelecimento.

3. Para que usamos os dados

  • Prestar o serviço: atendimento por IA, pedidos, mesas, caixa, estoque, financeiro, relatórios e notas fiscais.
  • Cobrar a assinatura, dar suporte e avisar sobre a conta.
  • Manter a segurança, evitar fraudes e cumprir obrigações legais e fiscais.
  • Melhorar o sistema, com dados agregados sempre que possível.

As bases legais são a execução do contrato, o cumprimento de obrigação legal, o legítimo interesse e, para promoções aos clientes dos estabelecimentos, o consentimento.

4. Com quem compartilhamos

Somente com fornecedores necessários para o serviço funcionar, que tratam os dados conforme a lei:

  • Hospedagem e banco de dados em nuvem.
  • Provedores de inteligência artificial, para gerar as respostas do atendimento.
  • Serviço de conexão com o WhatsApp.
  • Instituições de pagamento (como Mercado Pago e Asaas) e emissores de nota fiscal (como Focus NFe), quando o estabelecimento conecta esses serviços.
  • Autoridades, quando houver obrigação legal ou ordem judicial.

Alguns desses fornecedores podem estar fora do Brasil. Nesses casos, a transferência segue as regras da LGPD.

5. Por quanto tempo guardamos

Enquanto a conta estiver ativa e, depois, pelo prazo necessário para cumprir obrigações legais (por exemplo, fiscais) ou exercer direitos. Após o cancelamento, o estabelecimento pode pedir a exportação dos dados por até 90 dias.

6. Segurança

Usamos conexão criptografada, separação dos dados de cada estabelecimento no banco de dados, controle de acesso por usuário e registro das ações. Nenhum sistema é totalmente imune a incidentes; se houver um incidente relevante, os afetados e a Autoridade Nacional de Proteção de Dados serão comunicados conforme a lei.

7. Seus direitos

Você pode pedir: confirmação do tratamento, acesso, correção, anonimização, portabilidade, exclusão, informação sobre compartilhamento e revogação do consentimento. Se você é cliente de um estabelecimento que usa a Lumos, o pedido deve ser feito primeiro ao próprio estabelecimento, e a Lumos ajuda no que for necessário.

8. Armazenamento no navegador

O sistema guarda no seu navegador algumas preferências (como o tema e os filtros) e, quando você está sem internet, as vendas do PDV até que sejam enviadas. Não usamos esse armazenamento para publicidade.
